# SmartCalc Manager 🧮

A modern calculator web app built with **HTML, CSS, Bootstrap, and JavaScript**.

## Features
- Perform calculations (+, -, ×, ÷)
- Save history using LocalStorage
- CRUD operations (Add, Edit, Delete, Display)
- Responsive design with Bootstrap

## Live Demo
 https://safya174.github.io/smartcalc-manager/
## Technologies
- HTML5
- CSS3
- Bootstrap 5
- JavaScript (DOM, LocalStorage)
